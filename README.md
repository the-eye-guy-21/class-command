# Class Command

A free, customizable classroom agenda and CHAMPS dashboard designed for touchscreen displays, iPads, and projectors.

## Features
- Save and switch between multiple lessons.
- Customize agendas, timers, CHAMPS, themes, and layouts.
- Use Photo Mode to display complete student directions.
- Download agenda PNGs for Schoology.
- Adjust screen size, enter fullscreen, and hide controls.

## Getting Started
Open Class Command in your browser or add it to your iPad Home Screen. Use **Setup** to customize your lessons and display.

## Saving Your Work
Lessons save automatically in your browser. Use **Setup → Backups and Starting Over** to export or import lessons between devices.

**Note:** No account or subscription required. Lessons do not sync automatically. Avoid including student information.
